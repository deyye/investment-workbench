## 追加轮次：设置页没有回头路（2026-09-17 上午）

用户反馈："模型设置页面没有返回按钮能回到点进来时的工作界面"。查下来不是一个按钮的事，是三件事叠在一起：

1. **设置页自身没有任何回退路径。** 入口是散的——工作台顶栏的「模型设置」、首页的模型状态胶囊、
   政策侧导航的「模型配置」（`/policy/settings/model` 被 303 跳过来）。从政策资料库第 3 页点进去配完模型，
   只能自己重新找回去。
2. **工作台顶栏五项长得一模一样，没有当前页高亮**（政策侧侧栏早有 `aria-current` + `nav-indicator`，
   两侧不一致）。"回不去"有一半是"不知道自己在哪"。
3. **即使自己找路回去，也会丢状态。** 政策侧顶栏只链到 `/policy/`，不带筛选、排序、页码。

### 做法：从来路判断，而不是给每个入口挂参数

入口分散且会继续新增，逐个挂 `?from=` 必然漏掉后加的那个，所以读浏览器自带的 Referer
（`workbench/server.py` 的 `return_target`）。三条规则：

- **只认同源。** 跨站 Referer 与协议相对地址（`//evil.example/x`）一律退回首页，避免拿外部输入当跳转目标。
- **`/policy/settings/model` 与 `/settings/model` 本身不能当返回目标**——回到它们会被 303 再弹回设置页，
  在界面上就是一个按了没反应的按钮。这是设计返回功能时容易漏的自我指涉。
- **查询串一起带回去**：`/policy/policies?sort=date&order=desc&per=50` 进、原样出。
  否则等于把人丢回列表开头，"回到当时的工作界面"就没做到。

页名用顶栏/侧栏的叫法（"政策资料库""材料质量"），不写 URL 片段——用户认的是名字。
判定不出来（书签直达、地址栏输入）就退回首页并写着「返回首页」，不猜、也不隐藏按钮。

### 改动与验证

新增 15 项断言（`tests/integration/test_workbench.py`）：8 个来源 → 目标页名与地址的参数化用例、
6 个必须退回首页的边界（含跨站与协议相对 URL 两个安全用例）、1 个高亮恰好一项且**不靠额外 class**
（样式走 `[aria-current=page]`，避免模板与 CSS 成为两处要同步的状态）、1 个端到端
（政策库 → 侧栏「模型配置」→ 303 → 设置页 → 返回，回到原筛选状态）。

**全量 447 passed / 10 skipped**（上轮 430 + 新增 17，无回归）。

视觉验收 3 张（Safari 真实渲染）：设置页左上角「← 返回政策资料库」、顶栏「模型设置」绿色高亮 +

于是用 `curl -H "Referer: ..."` 取回真实渲染的 HTML、把静态资源改成绝对地址后落到本地用 Safari 打开——

## 追加轮次：三块前端统一视觉语言（2026-09-17 上午）

用户反馈"前端页面不够统一，风格最好统一，不要频繁出现补充功能的小字"。查下来三套前端确实是三套独立设计：

| | 工作台 | 政策 | 审批 |
| --- | --- | --- | --- |
| 布局 | 白顶栏 + 居中单栏 | 深蓝左侧栏 + 工作区 | 深蓝顶栏 + 三栏 |
| 主色 | **绿 `#147d72`** | 深蓝 `#142e4c` + 蓝 | 深蓝（与政策同源） |
| 次要文字 | `#627487` | `#738297` | `#626f81` |
| 标题 | 34px | 27px | 26px |
| 圆角 | 7 档（6~16px） | 7 档（2~10px） | 8 档 |
| 字号 | 13 档 | **22 档（8/9/10px 用了 60 处）** | 11 档 |
| 聚焦环 | 浅绿 | **金色 `#b09564`** | 中蓝 `#4c7caa` |
| 变量命名 | `--line` | `--line` | `--border` |

**方向由用户选定**：沿用深蓝体系（只改工作台配色）+ 布局不动只统一视觉语言。

### 改了什么

1. **令牌统一**：三套 `:root` 用同一套值——`--brand:#245e98`、`--brand-ring:#5b8fc4`、
   `--ink`、`--muted:#5d6f85`、`--line`、`--bg`、圆角三档（`--r-sm/md/lg` = 6/9/14px）。
   审批侧的 `--border` 改名 `--line`（22 处），三套命名对齐。
2. **工作台换色**：绿 → 深蓝。关键点是 **`--green` 当时兼任品牌色与语义色**，
   必须拆开：导航/按钮/标题强调改 `--brand`，而「模型已就绪」状态点与保存成功消息保留
   `--ok`（绿）——绿色在这些位置是**语义**不是品牌。顺带修掉一处：状态徽标原为单一浅绿，
   会把"失败"也显示成绿，改为中性品牌色。
3. **字体统一**：三套共用 `--font`（PingFang/CJK 无衬线栈）与 `--font-serif`。
   初次排查时我误判"政策侧用衬线体"，实际它 `body` 用的是 `font:` **简写**，
   正则只搜 `font-family:` 会漏——这点已写进技能。衬线保留在三处刻意的位置
   （政策正文 `pre.content`、侧栏标语、品牌标）。
4. **字号收敛**：最小档从 8px 提到 11px，11px 整体提到 12px（政策 113 处、审批 34 处）。
   用占位符两步替换，避免 8→11 之后又被 11→12 连锁改写。页面主标题三套统一 28px。
   **未动**媒体查询里的响应式降级值与指标数字档位（那是有意的设计）。
5. **小字精简**：删掉"解释系统怎么实现"的整段，保留"你需要注意什么"的操作提示与风险警示。
   例：工作总览删掉"系统自动检查材料、判断政策并留存依据…"整行；采集来源删掉页脚
   "每次采集依次完成文件发现、下载解析…"整行；模型设置两段长说明各压成一行；
   危险操作（清空数据）的备份与口令警示**原样保留**。

### 字号提升带出的两个副作用（已修）
