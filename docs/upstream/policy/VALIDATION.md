## 浙江发改动态列表接通验证（2026-09-09）

栏目 `https://fzggw.zj.gov.cn/col/col1229565788/index.html` 的列表不在静态 HTML 中，而是通过 `<script … AuthorizedRead/unitbuild.js>` 声明构建参数、由前端 GET 公共页面构建接口动态生成。适配方式为「栏目页读参数 → 逐页请求构建接口（`paramJson` 携带 `pageNo`/`pageSize`/`search`）→ 解析返回的 `data.html` 列表」，不执行网页脚本。

实测（`scripts/zj_live_check.py`，2026-09-09）：

- 请求 27 页后停止（第 27 页为空响应即自停，未到 `max_pages=40` 上限），耗时约 14s；
- 去重后详情链接 **387 条**，覆盖 2026-06 新近文件至 2020-01-07 发布（最早成文 2019-12-31）；
- 新旧路径并存：新 `/col/…/art/` 结构 6 条、旧 `/art/` 结构 381 条，均被 `include` 与 `detail_url_pattern` 覆盖；
- 对最旧一条真实详情页做端到端解析：注册适配器 `_zjfgw_detail` 命中，文号 `浙发改能源〔2019〕532号`、成文 2019-12-31、发布 2020-01-07、附件 1 个（doc）均正确抽取；
- 构建接口 JSON 原件逐页落盘留证（`data/_live_check/zjfgw_gsgg/`）。

**真实入库**（隔离库，`--source zjfgw_gsgg --prefer rule --limit 15`，2026-09-09）：发现 387 条 → 下载/解析 15 条全部入库待复核；附件 11 个下载成功、2 个网关限流失败（可补采自愈）、6 个 WPS/旧 DOC 保留原件待解析；分类样例命中准确（招投标监管→准入/激励约束、新能源上网电价改革→激励约束/准入等）。

本次为**列表发现链路验证**，未对 387 条全量执行正文入库；入库由 `run_source` 对发现链接逐条 `ingest`。

## 江苏发改通知公告接通验证（2026-09-09）

来源 `jsfgw_tzgg`（江苏省发展改革委 · 通知公告 col284）。站点机制为 hanweb/TRS jpage：列表首页由服务端以 `<script>` 内嵌 `<datastore><recordset><record><![CDATA[<li><a…>]]>` XML 序列化输出；`ListPageParser` 已增加展开该内嵌记录的通用能力（剥 CDATA 后并入解析），详情页正文 `div.TRS_Editor`，新增 `site_adapters._jsfgw_detail` 清洗 `<title>` 站点前缀。

实测（隔离库，`--source jsfgw_tzgg --prefer rule --limit 5`，2026-09-09）：

- 列表发现 30 条（最新公告），`detail_url_pattern` 精确锁定 `art_284_` 栏目码，解读/导航链接零误收；
- 两批真实入库 7 条待复核，重复运行 policy_key 无重复（幂等成立）；规则排除 3 条非政策内容；
- 该栏目混有成品油调价、招聘公示等非政策文件，待复核噪音较高；投资政策价值有限，业务使用建议后续改接规范性文件目录。

## 尚不能宣称完成的事项

1. 未配置 `LLM_API_KEY`、`LLM_MODEL`，本次真实模型调用数为零，无真实分类准确率或推理成本结论。模拟接口测试不替代真实 API 验证。
2. 浙江列表发现链路已接通（见上），但**未对 387 条执行全量正文入库与双轮连续性运行**；旧路径页面正文有时仅含印发语、正文实体在 doc 附件中，需抽样确认入库正文质量后，再宣称浙江栏目全量接入完成。
3. 重庆只是外省试点，不代表全国各省覆盖。
4. 未部署长期后台服务；用户启动 `schedule` 后才会定期运行。
5. PDF 文本解析不包含 OCR；OFD、旧 DOC、表格附件和压缩包尚未实现正文解析，均保留原件及处理状态。
6. 没有完整有效性知识库，不自动断言政策当前有效；成文日、发布日期、同文号及采集版本都不等同于法律效力判断。

## 建议的最终验收

先配置单位允许的模型服务，用同一批独立人工标注样本评价相关性、四类分类及复核耗时；再验收浙江与优先外省的列表发现、标题日期文号、正文及附件。至少连续运行两轮，检查新文件新增、相同文件不重复、失败补采及人工确认不被覆盖。业务准确率的目标值应由指导员结合使用方式确定，不能把未经测量的百分比写成已经达到。
